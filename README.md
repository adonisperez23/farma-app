# MediAhorro Frontend

Plataforma de ahorro saludable construida con Ionic Vue 3, TypeScript y Tailwind CSS.

## Tecnologías

- [Ionic Framework](https://ionicframework.com/) - UI components
- [Vue 3](https://vuejs.org/) - Framework de frontend
- [TypeScript](https://www.typescriptlang.org/) - Tipado estático
- [Vite](https://vite.dev/) - Build tool
- [Tailwind CSS v4](https://tailwindcss.com/) - Estilos utilitarios
- [pnpm](https://pnpm.io/) - Gestor de paquetes

## Instalación

```bash
pnpm install
```

## Desarrollo

```bash
pnpm dev
```

## Build

```bash
pnpm build
```
